Reference
Hsig significant wave heightThe usual wave height of a month, a typical size for the sea in that period.
Hmax maximum wave heightThe tallest single wave of the month. These extreme waves cause the damage, and they get larger over the years (climate change).
load changeOne wave hitting the steel structure. More waves mean more load changes, which is what wears the steel out over time (fatigue).
cumulative loadThe running total of load changes, added up month by month. It only ever goes up. That total is what finally exceeds the structure's limit.
fatigue limit (Eq. 3)For a given number of load changes, the tallest wave the structure can still take. As load changes grow, this tolerable height gets lower.
phigh / plowThe chance of a unit breaking: higher once the structure's limit is exceeded (phigh), lower while it is still safe (plow). The first month it reaches phigh is the "probable failure" date.
StatusThe share of units (turbines + platforms) that are working right now. 1.0 = everything up, 0 = all down.
resilience / AEThe main result number: the total energy delivered over the whole period (the area under the energy curve, in MW·month). A larger value means the option delivers more energy.

Energies 2023, 16, 4771. https://doi.org/10.3390/en16124771. Features wave-driven fatigue, structural degradation and network resilience for the three end-of-life strategies.

Introduction

An offshore wind farm is licensed for about 25 years. When that permit expires (the end-of-life, EOL), the operator must pick a strategy. The paper compares the three standard options. This dashboard lets you reproduce its results and see how they change:

Decommissioning: take the old plant down and, later, build a new, modern one (there is downtime in between).
Extension: keep the current turbines running and simply maintain their safety.
Repowering: keep the old foundations but put bigger, more efficient turbines on top.

The risk the paper measures is taller waves caused by climate change, because taller waves wear out (fatigue) the steel structures over decades.

The simulation starts in 2015 and runs for 60 years (720 months).

Structure
1Waves & load: build a 60-year record of waves, count how many load changes each month puts on the steel, and show the fatigue limit (how much load a structure can survive).
2Cumulative load: add the load up month by month and find when the structure reaches its "probable failure" point.
3Network & energy: turn those failure chances into turbine outages across a network of platforms, then read off status and energy output.

Drag any slider and every figure updates live. The whole chain is recomputed. Legends sit to the side and scroll, so every curve label stays visible. All randomness uses a fixed seed, so results are reproducible. Key terms and the core rules are in the Info panel (top-right).

1

Build the wave record and estimate the monthly load

First we create a realistic 60-year sea record. Each month gets a significant wave height Hsig (the usual wave size) and a taller maximum wave height Hmax (the extreme, which grows over the years to model climate change). From that we count how many waves hit the structure (load changes) each month, only counting waves higher than Hmin, and plot it all. The last figure compares the fatigue limits of the old structures versus the new build, that is, how many load changes each can survive at a given wave height. These numbers drive everything that follows.

Eq. 1How common each wave height is
f(x; σ) = xσ² · e−x²2σ²

Shows how often a wave of height x occurs. Multiplied by the number of waves in a month, it estimates how many times a given height hits the structure.

Eq. 2From typical height to maximum height
Hmax = Hsig + | U( 0 , Hsig · (0.07·(year − baseYear) + 3) ) |

Turns a month's usual height Hsig into its taller maximum Hmax. The extra amount grows with the years due to climate change and is capped at 20 m (so Hmax ≤ Hsig + 20). That cap is not stated in the paper — it comes from the reference code and keeps the 60-year record realistic as the climate term grows.

2

Add up the load changes over time

Load changes do not disappear. They build up. It is that running total (cumulative load), added up month by month, that wears out the steel. Each curve here is one wave height: the higher the wave, the rarer and more damaging it is. The moment that height's running total crosses the limit set by Eq. 3, the chance of the structure breaking in that month jumps from plow to phigh. The solid "probable failure" line marks that first month. Which curve you see depends on the operation mode above: keep the structure running and the load only ever grows; decommission it and the running total resets to zero during the downtime, then the rebuild is stronger, pushing the probable-failure date further out.

3

Build the substation network, simulate damage and show the results

Here the chances from Chapter 2 become a working power plant. We build a network of numOSS · numTurbinesPerOSS + numOSS units, the turbine clusters plus their substation platforms, and each of these can also break. In any month whose waves pass the damage threshold, every unit is allowed to break with the chance computed in Chapter 2; a broken unit then stays offline for 2 months (the repair rule) before it works again. Status (top) is simply the share of units still working, so dips show outages. Energy output (bottom) is the total power (MW) of the working units. In Decommissioning and Repowering modes the per-turbine output is lowered then raised again (or stepped up) around end-of-life, which is why the curve changes shape there.
