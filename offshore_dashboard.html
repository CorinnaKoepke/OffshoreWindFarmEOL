Reference
Hsig significant wave heightThe "typical" wave height of a month (roughly the mean of the larger waves). Used to model the everyday sea state.
Hmax maximum wave heightThe tallest wave of a month. This is the extreme that drives damage; it grows over the years to represent climate change.
load changeOne wave hitting the steel structure. More waves (taller months) means more load changes, which is what fatigues the steel.
cumulative loadThe running total of load changes, summed month by month over the decades. It only goes up — that accumulation is what eventually exceeds the design limit.
fatigue limit (Eq. 3)For a given number of load changes, the tallest wave the structure can still tolerate. As load changes grow, the tolerable height drops. It is the "structural resistance curve".
phigh / plowThe failure probability used in a month after the limit is exceeded (high) versus before (low). The first month to reach phigh is the "probable failure" date.
StatusThe fraction of network units (turbines + platforms) that are currently working. 1.0 = everything up, 0 = all down.
resilience / AEThe paper's headline number: the area under the energy-output curve over the whole horizon (MW·month). Bigger = the option delivers more energy over time.

Repair
month [t, t+1, t+2] → [ broken, broken, working ]
If a unit breaks in month t, it stays offline for 2 months, then is back online. This 3-month pattern (0 = down, 1 = up) means repair windows never overlap and a unit cannot re-break in the month it is being repaired.

Energies 2023, 16, 4771. https://doi.org/10.3390/en16124771. Features wave-driven fatigue, structural degradation and network resilience for the three end-of-life strategies.

Introduction

An offshore wind farm is licensed for about 25 years. When that permit expires (the end-of-life, EOL), the operator must pick a strategy. The paper compares the three standard options — this dashboard lets you reproduce its results and see how they change:

Decommissioning — remove the old plant and later build new, modern structures (downtime in between). Extension — keep the existing turbines running and just maintain their safety. Repowering — keep the old foundations but install bigger, more efficient turbines on top.

The risk the paper quantifies is rising wave heights caused by climate change, because taller waves fatigue the steel structures over decades.

2

Generate wave heights data and estimate the expected load

First we invent a realistic 60-year sea state. Each month gets a significant wave height Hsig (typical, from a Rayleigh distribution) and a taller maximum height Hmax (the extreme, grown over the years via Eq. 2 to model climate change). We then count how many load changes — waves above Hmin — each month contributes (Eq. 1), and plot all of it. The last figure compares the fatigue limits of the old structures versus the new build, i.e. how many load changes each can survive at a given wave height. Everything downstream is driven by these numbers.

Eq. 1Rayleigh wave-frequency distribution
f(x; σ) = (x / σ²) · e^( −x² / 2σ² )

Gives the frequency of a significant wave height x. Multiplied by the monthly load-change count, it estimates how many times a given height hits the structure.

Eq. 2Maximum wave height from significant height
Hmax = Hsig + | plus | ,  plus = U( 0 , Hsig · (0.07·Δyear + 3) )

Turns a month's Hsig into its taller Hmax, adding a random increment that grows with the years since the base year (climate trend), capped at maxH.

Parameters — wave climate & load
Total number of waves a month is assumed to hit the structure. It multiplies the Eq. 1 wave frequency, so it sets the height of the "load changes over time" curve and how fast cumulative load (Ch. 4) builds up — a larger value means the structure reaches probable failure earlier. (The paper derives ≈ 2.6×10⁵ per month from a ~10 s wave period.)

3

Calculate the cumulative sum of load changes over time

Load changes never disappear, they accumulate — and it is that accumulated total (cumulative load), summed per discrete wave height, that fatigues the steel. Each curve here is one wave-height band: the higher the band, the rarer the waves, but the more damaging. The moment a band's accumulated count crosses what Eq. 3 allows, that month's failure probability jumps from plow to phigh — that first month is the solid "probable failure" line. Left: the structure is kept in continuous use, so the load only ever grows. Right: the structure is decommissioned (the running total is reset to zero during the downtime) and rebuilt stronger, so the failure is pushed further out — the core reason the decommissioning option survives longer.

4

Create an offshore substation (OSS) network, destroy something and plot the performance

This is where the abstract probabilities become a running power plant. A flat network of numOSS · numTurbinesPerOSS + numOSS units is built (the turbine clusters plus their substation platforms, each of which can also break). In any month whose waves clear the damage threshold, every unit is allowed to fail with the probability computed in Chapter 4; a broken unit then stays offline for 2 months (the repair rule) before it can run again. Status (top) is simply the fraction of units still working, so dips show outages. Energy output (bottom) is the total MW of working units — in Decommissioning and Repowering modes the per-turbine output is ramped down then back up (or stepped up) around end-of-life, which is why the curve changes shape there. The area under that energy curve is the paper's headline resilience number.
