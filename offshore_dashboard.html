Offshore Wind Farm End-of-Life — Interactive Resilience Dashboard Mode: Decom

Recreates the plots of "Testing Resilience Aspects of Operation Options for Offshore Wind Farms beyond the End-of-Life" (Köpke, Mielniczek & Stolz, Energies 2023, 16, 4771) as interactive charts. Adjust any parameter and the whole model recomputes — waves, load changes, degradation time, decommissioning window, turbine/OSS status and energy output.

Operation mode

Decomissioning models a rebuild gap between end-of-life and Rebuild; Extension/Repowering ramp the output power over time.

Load / structure limits

OSS network & damage

Randomness

Recompute runs automatically on every change (debounced). Use a different seed to explore other stochastic realisations. Turbine/OSS failure, status & energy depend on mode and the current time step, so recompute re-samples them.

1 · Synthetic wave heights

Maximal & significant wave height over the simulation period (monthly samples).

2 · Wave-height distribution

Density of Hsig and Hmax vs the reference Rayleigh distribution.

3 · Expected load (load changes per month)

Sum of estimated load changes for all wave heights above Hmin in a given month.

4 · Failure threshold (load changes ↔ wave height)

Wave height at which the design load budget is exceeded for p = 0.1 / 0.5 (log-x).

5 · Cumulative load changes (existing structures)

Cumulative sum per discrete wave height, log-y. Dotted = end-of-life, solid = degradation time.

6 · Cumulative load changes (decommissioning reset)

Cumulative sum that resets to zero during the decommissioning window (decom → rebuild).

7 · Network status

Fraction of turbines + OSS currently operational.

8 · Energy output [MW]

Total operational power, mode-dependent.

Adapted from MainOffshoreWave.py · Fraunhofer EMI · Köpke, Mielniczek & Stolz (2023). Stochastic model re-implemented in JavaScript with a seeded RNG; results are illustrative, not a direct reproduction of any single published figure.
